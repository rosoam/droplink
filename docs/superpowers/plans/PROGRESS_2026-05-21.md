## 🟠 Task 5 — BLE Advertiser : STUB INTERMÉDIAIRE COMMITÉ

**Status :** ⏸ STUB en place, **rewrite natif requis**
**Commit stub :** `1b89882`
**Fichier :** `src-tauri/src/ble.rs`

### Découverte bloquante
`bluest 0.6` (ajouté dans `Cargo.toml`) **ne supporte que GAP Central + GATT Client**.
Peripheral/Server roles **non supportés** → impossible d'advertiser via bluest.
API présumée par le plan (`CharacteristicBuilder`, `Adapter::start_advertising`, etc.) **n'existe pas**.

### Décision utilisateur (verbatim)
> "BLE = killer feature, on investit 1-2j"

→ **Rewrite natif** : `objc2-core-bluetooth` (macOS) + `windows-rs` Gatt* (Windows).

### Surface publique à PRÉSERVER pour le rewrite
```rust
pub const DROPLINK_SERVICE_UUID: Uuid = uuid!("A7B8C9D0-E1F2-3456-789A-BCDEF0123456");
pub const DROPLINK_INFO_CHAR_UUID: Uuid = uuid!("B7C8D9E0-F1A2-3456-789B-CDEF01234567");

pub struct BleDeviceInfo { pub name: String, pub ip: String, pub port: u16 }

pub mod advertiser {
    pub async fn start(name: &str, ip: &str, port: u16) -> Result<(), String>;
}
```
